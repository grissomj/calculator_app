# Calculator App 

This is a command-line calculator app created as a solo project for Lab 11.

##  Features

- Add, subtract, multiply, divide
- Square root and exponentiation
- Handles invalid input and divide-by-zero
- User-friendly prompts via the command line

## How to Run

1. Install Python 3.x
2. Open a terminal or PowerShell
3. Navigate to the folder
   ```bash
   cd path\to\calculator_app
