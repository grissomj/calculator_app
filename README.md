# calculator_app

This is a command-line calculator app created as a solo project for Lab 11.

## 🔧 Features

- Basic operations: add, subtract, multiply, divide
- Advanced operations: square root, exponentiation
- Handles invalid input (non-numeric, divide by zero)
- Easy-to-use CLI prompts

##  How to Run

1. Install Python 3 if you don't have it already
2. Open a terminal in the project folder
3. Run this command:

```bash
python calculator.py
